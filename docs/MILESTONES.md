# AETHER SENTINEL AI Milestones

## Purpose

This document defines the milestone system for AETHER SENTINEL AI.

Milestones should help connect product phases, GitHub issues, deliverables, and completion reports.

## Milestone 0: Foundation

Status: Completed

Goal:

Complete product foundation.

Deliverables:

- Architecture documentation.
- Brand guideline.
- UI design system.
- GitHub workflow documentation.
- Issue templates.
- Documentation structure.
- Automatic update workflow reservation.
- Phase 00 completion report.

Acceptance criteria:

- Core documentation files exist.
- GitHub issue templates exist.
- Repository governance is documented.
- Future update system has reserved architecture and workflow locations.
- No production business code is created.

## Milestone System

The milestone system must support future:

- Development.
- Testing.
- Release.
- Maintenance.

## Milestone Fields

Each milestone should define:

- Name.
- Goal.
- Scope.
- Deliverables.
- Acceptance criteria.
- Risks.
- Related phase report.

## Phase And Milestone Mapping

Each phase should map to one or more GitHub milestones.

Rules:

- A phase may contain multiple milestones if scope becomes large.
- A milestone should not contain unrelated work.
- Completion must be documented in a phase report.
- Important changes must be reflected in `docs/`.
